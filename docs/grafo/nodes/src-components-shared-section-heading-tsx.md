# SectionHeading

Cabeçalho reutilizável de seção (eyebrow, título, descrição) usado em depoimentos e experiência.

## Responsabilidades

- Padronizar tipografia dos intros de seção.

## Entradas e saídas

- Entrada: props de texto/classe.
- Saída: markup do heading.

## Dependências

- `cn` de `src/lib/utils.ts`.

## Decisões e cuidados

- Pequeno; existe para manter consistência visual entre páginas.
