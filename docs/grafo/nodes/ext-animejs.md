# anime.js

Biblioteca de animação (v4) usada em `scroll-motion` para entradas de seção no scroll.

## Responsabilidades

- Timelines e `onScroll` sem repetir.

## Entradas e saídas

- Entrada: elementos marcados no DOM.
- Saída: animações de opacity/y.

## Dependências

- Pacote npm `animejs`.
