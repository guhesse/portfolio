# matter-js

Motor de física 2D usado pelas tags do hero.

## Responsabilidades

- Simular corpos, mouse constraint e forças das ferramentas.

## Entradas e saídas

- Entrada: API do engine no browser.
- Saída: posições das tags.

## Dependências

- Pacote npm `matter-js`.

## Decisões e cuidados

- Carregamento adiado no hero.
