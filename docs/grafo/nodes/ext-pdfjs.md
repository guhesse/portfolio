# PDF.js

`pdfjs-dist` para rasterizar páginas de manuais e pitch decks no carrossel.

## Responsabilidades

- Decodificar PDF no cliente e desenhar em canvas.

## Entradas e saídas

- Entrada: URL/asset do PDF.
- Saída: bitmaps de página e thumbs.

## Dependências

- Pacote npm `pdfjs-dist`.
